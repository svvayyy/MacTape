# Contributing to MacTape

Thank you for helping make recording simpler.

Open an issue before beginning a large feature or architectural change.

## Expectations

- Keep changes focused and reviewable.
- Include tests for behavior changes.
- Preserve local-only operation.
- Avoid new settings when a good default works.
- Do not introduce analytics, telemetry, accounts, cloud features, AI features, or hidden network activity.
- Do not commit captured media, personal paths, signing identities, credentials, or machine-specific files.

## Verification

Run the MacTape test target and build the MacTape scheme before opening a pull request.

Explain what changed, why it belongs in MacTape, and how it was verified.
