# MacTape Privacy

MacTape records locally and does not operate a network service.

## Data handling

MacTape does not collect, transmit, sell, or analyze personal data.

MacTape does not include analytics, telemetry, advertising frameworks, crash-reporting services, or hidden network requests.

Screen and audio content is written directly to the save folder selected on the Mac.

## Permissions

Screen Recording permission allows MacTape to capture the selected display or window.

Microphone permission is requested only when microphone recording is enabled.

MacTape does not request camera, contacts, location, calendar, photo library, or accessibility access.

## Recordings

Recordings belong to the user.

MacTape does not upload, copy, index, transcribe, summarize, or inspect completed recordings.

Deleting MacTape does not delete recordings saved outside the application.

## Verification

The complete source is public so these claims can be inspected.
