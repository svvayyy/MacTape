Privacy Policy

ClipTape records locally and does not operate a network service. Your recordings stay on your Mac.

Applies to ClipTape 1.0 and later
On this page Data handling Permissions Recordings Network activity Verification Contact

Data handling

ClipTape does not collect, transmit, sell, or analyze personal data.

ClipTape does not include analytics, telemetry, advertising frameworks, crash-reporting services, or hidden network requests.

Screen and audio content is written directly to the save folder selected on the Mac.

  • No account, sign-in, or user identifier of any kind.
  • No data is linked to you, because no data is collected.
  • No data is used to track you across apps or websites.

Permissions

ClipTape asks for the smallest set of system permissions that a screen recorder can function with, and it asks for each one only at the moment it is needed.

  • Screen Recording allows ClipTape to capture the selected display or window.
  • Microphone is requested only when microphone recording is enabled.
  • ClipTape does not request camera, contacts, location, calendar, photo library, or accessibility access.

ClipTape runs inside the macOS App Sandbox with a hardened runtime. Its file access is limited to the save folder you select.

Recordings

Recordings belong to the user.

ClipTape does not upload, copy, index, transcribe, summarize, or inspect completed recordings.

Deleting ClipTape does not delete recordings saved outside the application.

Network activity

ClipTape has no account system, no cloud service, and no server component. The app does not phone home, check licences, or fetch remote configuration.

This website is a separate, static page hosted on GitHub Pages. When your browser loads it, the star count in the navigation bar is read from GitHub's public API. GitHub receives the normal request metadata associated with that connection, such as your IP address and browser headers. This request has nothing to do with the ClipTape app or recordings on your Mac.

Verification

The complete source is public so these claims can be inspected. If a claim on this page is not supported by the code, that is a bug, and it should be reported.

Read the source PRIVACY.md in the repo

Contact

Questions about this policy, or about how ClipTape handles anything on your Mac, are best asked in the issue tracker so that the answer is public and stays public.

If your question should not be public, email hello@swayyy.dev instead. That address is also the support contact for the app itself.

Please do not include private recordings, credentials, or personal file paths in a public issue. Report security vulnerabilities privately by email, following the instructions in SECURITY.md.
